# Security Policy

## Supported Scope

This repository is a reference architecture and policy baseline. Security reports are accepted for:

- Terraform definitions in this repository
- Rego policies and policy tests
- CI/CD security gates and supply-chain configuration

## Reporting a Vulnerability

For sensitive findings, do not open a public issue.

Please report privately by contacting the maintainer through GitHub security reporting or direct maintainer contact.

Include:

- Affected file(s) and component(s)
- Reproduction steps / proof of concept
- Potential impact
- Suggested remediation (if available)

## Response Targets

- Initial acknowledgment: within 5 business days
- Triage and severity assessment: within 10 business days
- Remediation timeline: based on severity and complexity

## Disclosure

Please allow time for triage and remediation before public disclosure.
